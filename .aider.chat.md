# Project Info for Aider

This is a TypeScript project, with NodeJS, NextJS & React. It is an early stage development project, so always assume the latest version of all tools and libraries. Backwards compatibility is not required.

## Tech Stack
- TypeScript >= 5.8
- React >= 19
- Tailwind >= 4.0
- NextJS >= 15

## Coding Approach/Standards
- All code/functions/components should be as reusable and generalizable as possible, with all options and parameters configurable, but all with reasonable defaults so minimum configuration is required.
- Ensure all suggested code compiles successfully with `tsc` before making any changes.

## Project Structure
- `src/` - all TypeScript source files are in this subdirectory. Only look here for source code 
- `dist/` - Compiled JS files built from TS source
